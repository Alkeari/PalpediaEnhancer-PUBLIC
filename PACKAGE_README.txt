Palpedia Enhancer
=================
Search, sort and filter the Palpedia, and clear the notification dot in seconds.
Requires Palworld on Steam and UE4SS Experimental (Palworld) from the Steam Workshop.

Install (Steam Workshop)
  Subscribe, launch Palworld, enable the mod under Options > Mod Management.

Got this file some other way (not a Steam Workshop subscription)?
  This package is built for the Steam Workshop loader, which installs by item ID
  (Steam\steamapps\workshop\content\1623730\3788253343\), not by dropping a folder in by hand.
  If you are not using Steam Workshop, use the Nexus Mods package instead: it installs directly
  into the Palworld game folder and needs no Steam subscription. Get it from
  https://www.nexusmods.com/palworld/mods/5307

Settings
  Assets\Settings.ini: hotkeys (ToggleUnreadKey, default Ctrl+N; ClearAllKey; MarkAllSeenKey),
  ShowMarkAllSeenButton, RememberState, VerboseLogging, and the state the Palpedia opens in
  (DefaultSort, DefaultSortDescending, DefaultUnreadOnly, DefaultSearchTargets). Every key is
  commented in the file with the values it accepts. This file is replaced when the mod updates.

Bug reports
  Steam Workshop page > Discussions > Bug Reports, or the Bugs tab on Nexus Mods. Include your
  UE4SS.log (Mods\NativeMods\UE4SS\UE4SS.log) with VerboseLogging=true, the mod version, the
  Palworld version from the title screen, your game language and your other mods.
